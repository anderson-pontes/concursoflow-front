# Registro de risco — dependências frontend

**Data:** 2026-08-22  
**Story:** 8.10 — Saneamento técnico e UX pós-auditoria  
**Escopo:** `npm audit --omit=dev`

## Resultado

- Baseline anterior: 19 vulnerabilidades de produção, incluindo 9 altas.
- Após a remediação: nenhuma vulnerabilidade alta de produção.
- Risco residual: 2 vulnerabilidades moderadas associadas ao React Router 6.

## Mudanças aplicadas

- Axios atualizado de `^1.7.0` para `^1.19.0`.
- React Router DOM atualizado de `^6.24.0` para `^6.30.6`.
- `@remix-run/router` resolvido em `1.23.4` pelo lockfile.
- CLI `shadcn` movido de `dependencies` para `devDependencies` e atualizado para `^4.19.0`.
- Dependências transitivas corrigidas com `npm audit fix --omit=dev`, sem uso de `--force`.

## Risco residual aceito temporariamente

O npm recomenda React Router DOM 7.18.2 para remover as duas ocorrências moderadas restantes. Essa atualização é uma mudança de versão principal e exige uma migração separada das rotas, guards, links e testes. Aplicá-la automaticamente com `npm audit fix --force` aumentaria o risco de regressão funcional.

Até a migração controlada para Router 7:

- URLs de navegação devem continuar sendo geradas internamente, sem aceitar destinos arbitrários não validados;
- redirects oriundos de parâmetros ou respostas externas devem ser normalizados para caminhos internos;
- o audit de produção deve continuar bloqueando severidade alta;
- a migração para Router 7 permanece registrada como débito moderado de tooling/segurança.

## Evidências

- `npm run lint`: aprovado após a atualização.
- `npm run typecheck`: aprovado após a atualização.
- `npm test`: aprovado após a atualização.
- Build e regressão E2E: executar no sign-off da story.

## Decisão

**CONCERNS controlado:** nenhuma vulnerabilidade alta permanece em produção; duas moderadas ficam aceitas temporariamente para evitar uma migração major não planejada dentro da correção de segurança.
